\section{Context and Positioning}

\subsection{Problem Context}

\begin{itemize}
  \item Federated IoT anomaly detection often trains a shared autoencoder.
  \item Detection requires a reconstruction-error threshold.
  \item Heterogeneous devices can have different benign reconstruction-error distributions.
  \item A shared threshold can impose unequal false-positive rates across clients.
  \item DATP studies threshold scope as the operating-point variable.
\end{itemize}

\subsection{DATP Rationale}

\begin{itemize}
  \item DATP fixes the model and training protocol.
  \item DATP varies only threshold calibration scope.
  \item This allows attribution to threshold policy rather than architecture or aggregation.
  \item The central question is whether local or grouped thresholds reduce per-client FPR disparity.
\end{itemize}
