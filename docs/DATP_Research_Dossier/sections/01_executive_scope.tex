% ---- Purpose ----
\section{Purpose}

\begin{itemize}
  \item Study threshold calibration scope in federated IoT anomaly detection.
  \item Isolate the threshold policy as the changing variable.
  \item Keep the FedAvg autoencoder and score artifacts fixed across B1--B4.
  \item Measure per-client false-positive-rate disparity.
  \item Compare shared, per-client, family-mean, and cluster-mean threshold policies.
  \item Bound claims to the tested datasets, partitions, seeds, and protocol.
\end{itemize}

% ---- Scope boundary ----
\section{Scope Boundary}

\begin{tcolorbox}[callout]
\begin{itemize}
  \item Threshold policy may change.
  \item Model architecture does not change.
  \item FedAvg protocol does not change.
  \item Score artifacts are reused across policies.
  \item B0 is a centralized reference only.
  \item Privacy, deployment, poisoning, and model personalization are out of scope.
\end{itemize}
\end{tcolorbox}
